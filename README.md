# MultiMC package for Arch Linux (moved)

This repository is no longer maintained. Install MultiMC on Arch Linux from the AUR:
[multimc-bin](https://aur.archlinux.org/packages/multimc-bin).

The AUR package's `PKGBUILD` is now made, with the `.deb` and `.rpm`, from one source:
[MultiMC/Packaging](https://github.com/MultiMC/Packaging) (`arch/PKGBUILD.in`, filled in by
`build.py`). From version 1.9 it builds from the wrapper's source tarball instead of
repackaging the `.deb`.

The `PKGBUILD` here is the last one from this repository, for the wrapper package 1.8, kept for
reference.

Questions: [Discord](https://discord.gg/multimc).
