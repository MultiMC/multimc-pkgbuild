# MultiMC package for Arch Linux (retired)

This repository is no longer maintained. Install MultiMC on Arch Linux from the AUR instead:
[multimc-bin](https://aur.archlinux.org/packages/multimc-bin).

The `PKGBUILD` here is the last one, for the wrapper package 1.8, whose first start downloads the
current Stable build of MultiMC. It's kept for reference.

Questions: [Discord](https://discord.gg/multimc).
